# VendaClara: downloads

Assistente de rentabilidade para vendedores do Mercado Livre (Windows 10 e 11).

- **Versão atual:** [VendaClara-Instalador.exe](https://github.com/pedrovcrm/vendaclara-downloads/raw/main/download/VendaClara-Instalador.exe)
- **Versões anteriores:** pasta [`download/`](download/). As 3 últimas ficam disponíveis; para voltar a uma delas, instale por cima. Seus dados são mantidos.
- **Integridade:** compare o SHA-256 do arquivo baixado com [`download/SHA256SUMS.txt`](download/SHA256SUMS.txt). No Windows: `certutil -hashfile VendaClara-Instalador.exe SHA256`.

Na primeira instalação, o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. O código-fonte é privado.
